# App Financeiro

Aplicativo de controle financeiro pessoal.

## Setup

```bash
# Instalar dependencias
npm install

# Configurar variaveis de ambiente
cp .env.example .env

# Rodar em desenvolvimento
npm run dev
```

## Estrutura do Projeto

```
src/          - Codigo fonte
tests/        - Testes
docs/         - Documentacao
scripts/      - Scripts utilitarios
```
